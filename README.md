# AptAge Dashboard - 아파트 단지 정보 분석 대시보드

이 앱은 공공데이터포털 및 자체 DB(포커스미디어, 타운보드)를 기반으로 아파트 단지별 세대원 연령대 분포를 시각화해주는 대시보드입니다.

## 🚀 주요 기능
1. **지역별 필터링**: 시/도 및 시/군/구별로 아파트 단지를 검색할 수 있습니다.
2. **단지 유형 구분**: 포커스미디어(Focus Media) 및 타운보드(TownBoard) 단지를 필터링하여 볼 수 있습니다.
3. **연령대 시각화**: Chart.js를 사용하여 단지 구성원의 연령대(10대~60대+) 분포를 파이 차트로 제공합니다.
4. **관리자 모드 (DB 업로드)**: 엑셀(XLSX, CSV) 파일을 드래그하여 앱의 기본 DB를 손쉽게 업데이트할 수 있습니다.

## 📂 파일 구조
- `index.html`: 대시보드 구조 및 UI 템플릿
- `style.css`: 현대적이고 직관적인 프리미엄 다크 테마 디자인
- `app.js`: 데이터 처리, 필터링 로직 및 차트 렌더링
- `implementation_plan.md`: 프로젝트 설계 및 향후 고도화 계획

## 🛠 사용 방법
1. 브라우저에서 `index.html` 파일을 직접 엽니다.
2. 왼쪽 하단의 **'관리자 모드'** 버튼을 클릭합니다.
3. 준비된 아파트 리스트 엑셀 파일을 업로드 영역에 드래그합니다.
   - 필수 컬럼 예시: `단지명`, `시도`, `시군구`, `세대수`, `10대`, `20대`...
4. **'DB 반영하기'** 버튼을 누르면 대시보드에 즉시 데이터가 적용됩니다.
5. 대시보드에서 지역을 선택하여 세부 데이터를 확인합니다.

## 💡 참고 사항
- 현재 데이터는 브라우저의 `localStorage`에 저장되어, 새로고침 후에도 유지됩니다.
- 초기 로딩 시 샘플 데이터(강남구, 성남시 등)가 표시됩니다.
- 엑셀 파싱을 위해 `SheetJS` 라이브러리를 사용하며, 인터넷 연결이 필요합니다 (CDN 방식).
